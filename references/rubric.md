# CUMS 评分细则

四个维度各 4 个检查项，共 16 项。每项 0–5 分，按同一把“证据阶梯”打分。

## 证据阶梯（16 项通用）

| 分数 | 档位 | 判断标准 |
|---|---|---|
| 0 | 没有 | 答不上来；或者说的和做的相反；或者证据表明这件事没做到 |
| 1 | 只有说法 | 口号式回答，或没有核实过的看法，举不出一个具体例子 |
| 2 | 零散做到 | 有例子，但靠个别人或个别时候，没有固定下来；或者知道问题但没有处理 |
| 3 | 成了规矩 | 稳定在做，能说出具体做法、流程或标准 |
| 4 | 经过考验 | 为它放弃过钱、订单或速度；或在压力下照样做到；或做过调整并看到结果 |
| 5 | 被人印证 | 做到了，并且有顾客、员工、伙伴的原话，或数据、公开记录，能独立证明 |

**阶梯量的是“这件事做到了什么程度”，不是“证据有多硬”。** 数据确凿地证明做得不好，照样是低分：后台显示复购率很低、订单主要靠满减，回头这一项就是 1–2 分，不因为“有数据”而给 5 分。只达到行业底线（例如证照齐全）是 3 分，不是 5 分。

打分只看行为和证据，不看说得多好听。“我们很重视品质”是 1 分；“每天收档前把没卖完的汤底倒掉”是 3 分；“因为这条规矩，放弃过一个要求隔夜备货的大单”是 4 分；“老顾客评价里反复提到汤头每天现熬”是 5 分。

## 证据类型与封顶

| 类型 | 含义 | 封顶 |
|---|---|---|
| 资料可见 | 你看到了原始材料：评价、聊天记录、数据表、公开报道、现场照片 | 5 |
| 用户陈述 | 对话里老板或团队自己说的，没有材料佐证 | 4 |
| 推断 | 从别的信息推出来的 | 3 |
| 待核实 | 信息不够，不打分 | — |

5 分必须有他人或数据的印证，老板自己说“顾客都夸我们”不算。原样贴进对话的评价、聊天记录、数据表，和截图、文件一样算“资料可见”。老板凭记忆转述的顾客说法、口头报的数字、说“有张表”但没给你看的，算“用户陈述”，封顶 4 分。

**数字类证据**（复购率、介绍占比等）：先看数字说明这件事做得好不好，再定档；数字好但只是口头报的，给到 3–4 分，看到原始数据才给 5 分。

**0 分和待核实的区别**：问到了却答不上来，或者说的和做的相反，是 0 分；资料里没提到、也没机会问，是待核实。

**用在“知道不知道、说不说得清”这类检查项上**（C1 初心、U1 需求、U4 复述、M1 趋势、M2 对手、S1 存在价值）：1 分是泛泛而谈；2 分是说得出个别具体情况；3 分是说得具体，并且持续在看；4 分是据此做过调整；5 分是有顾客原话或数据印证。

## C 核心价值与文化（根）

| ID | 检查项 | 看什么证据 |
|---|---|---|
| C1 | 初心：为什么做这门生意 | 具体的起因、时间、人和事，不是“想做一个好品牌” |
| C2 | 底线：不肯妥协的事 | 一件明确不做的事，以及为它付出过什么 |
| C3 | 承诺：对顾客说到做到 | 承诺的内容，和日常做法是否一致 |
| C4 | 内部一致：团队照着做 | 员工是否知道并按此做事，有没有对应的规矩 |

## U 用户连接

| ID | 检查项 | 看什么证据 |
|---|---|---|
| U1 | 需求：顾客买它是为了解决什么 | 顾客的原话或真实购买场景，不是老板的想象 |
| U2 | 落差：顾客在哪个环节不满 | 常见抱怨是什么，有没有处理 |
| U3 | 回头：复购与推荐 | 复购、转介绍的事实或数字 |
| U4 | 复述：顾客怎么向别人介绍它 | 顾客自己的说法，是否和品牌想传达的一致 |

有渠道、经销或 B2B 时，U1–U4 按两级用户分别找证据。两级都有证据时，取较低的一级打分，并写明两级各自的情况。只有直接客户的证据时，按直接客户打分，把最终使用者那一级写进待核实，不因此扣分。

## M 市场敏感度

| ID | 检查项 | 看什么证据 |
|---|---|---|
| M1 | 趋势：行业正在发生什么变化 | 说得出具体变化，以及对自己的影响 |
| M2 | 对手：谁在抢同一批顾客 | 说得出直接对手和替代选择，以及他们近期的动作 |
| M3 | 差异：对手做不到或不愿做的事 | 具体是什么，为什么别人做不了或不肯做 |
| M4 | 调整：最近一次因变化做的改动 | 什么时候、改了什么、结果如何 |

## S 社会角色与价值

| ID | 检查项 | 看什么证据 |
|---|---|---|
| S1 | 存在价值：品牌不在了，谁会少了什么 | 除了“少一个卖家”之外的具体损失 |
| S2 | 上下游：谁因它过得更好 | 员工、供应商、合作方、社区的具体受益 |
| S3 | 经得起看：经营方式能否长期并公开 | 合规、不靠透支顾客或员工、出事后的处理方式 |
| S4 | 站位：和谁站在一起 | 合作对象、行业参与、公益行动是否与信念一致 |

小微企业的 S 不要求做公益。把员工带好、不坑供应商、对街坊诚实，都是真实的社会角色，按证据阶梯照常打分。

## 打分纪律

1. 每个打了分的检查项都要写出证据。写不出证据就标“待核实”，不打分。
2. 一个事实确实回答了两个检查项的问题，两处都可以用。例如“只用日晒、所以只在本省卖”，在 C2 证明底线，在 M3 证明对手不愿做。但不要把同一句话换个说法，凑到答不上来的检查项里。
3. 证据不足时宁可少打分，不靠想象补齐。
4. 不因为老板态度诚恳、行业前景好或设计好看而加分。
5. C 的分数只看根是否真实稳定，不看表达是否漂亮。
