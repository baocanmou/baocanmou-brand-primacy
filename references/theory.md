# 品牌源力理论要点

品牌源力（Brand Primacy）由易慧庭提出，登记著作权人为南昌包参谋品牌策划有限公司（赣作登字-2023-A-00132773）。本文件是执行本技能所需的要点摘录，不是原著全文。

## 1. 定义

品牌源力是品牌与生俱来、能助力品牌发展的原生动力。它从这门生意里长出来，不是策划出来的。

品牌发展靠两样东西：源力（内在，看不见）和价值（外显，看得见）。源力推动价值，价值反哺源力。视觉让品牌被看见，源力让品牌被相信。

## 2. 公式

```
P = C × U × M × S
```

| 维度 | 含义 | 核心问题 |
|---|---|---|
| C 核心价值与文化 | 品牌的信仰、承诺和内部行动准则 | 品牌的灵魂是什么？ |
| U 用户连接 | 对顾客需求、痛点、期望的理解和满足 | 品牌怎样与顾客建立真实的联系？ |
| M 市场敏感度 | 对趋势、对手、顾客行为变化的感知和调整 | 品牌怎样适应变化的市场？ |
| S 社会角色与价值 | 品牌对上下游和社会的作用 | 品牌在社会里扮演什么角色？ |

**为什么用乘号**：任何一项接近 0，整体就接近 0。强项补不了短板，所以先补最短的那一项，再谈放大。花更多钱做传播，救不了没有核心价值的品牌。

**怎么算**：四项各 0–10 分，综合指数用几何平均 `G = (C×U×M×S)^(1/4)`，结果仍是 0–10 分，并保留乘法的短板效应。例如三项 10 分、一项 2 分，G 约 6.7，且因该项不高于 3 分，直接按“弱”处理。

| 档位 | 条件 | 该做什么 |
|---|---|---|
| 强 | G ≥ 8，且没有任何一项 ≤ 3 | 放大并坚持 |
| 中 | 5 ≤ G < 8，且没有任何一项 ≤ 3 | 先补短板，再设计表达 |
| 弱 | G < 5，或任一项 ≤ 3 | 回去找根、补证据，不做放大 |

## 3. 根与表达

源力有两层，不能混在一起：

- **不变的根**：创始初心，创始人和团队不肯妥协的信念。它在 C 里，通常在创立时就定了。
- **流动的表达**：这个根怎样在 U、M、S 里被感知、被验证、被重新说出来。顾客在变、市场在变、社会议题在变，表达必须跟着更新。

一句话：根不轻易变；根怎么被讲、被感知、被验证，一直在变。

判断一个动作时先问：这是在换表达，还是在动根？换表达是正常经营；动根通常意味着这已经不是同一个品牌。

## 4. 四维之间的关系

- C 定方向。没有 C，其余三项没有锚。
- U 和 M 互相校验：顾客反馈和市场观察要对得上。
- S 是更大的 U：把顾客放回社会里看。
- M 是预警：提醒表达是否需要更新。

涉及渠道、经销或 B2B 时，U 要看两级用户：直接付钱的客户，和最后使用的人。两级的需求不同，不能用同一套话。

## 5. 三个阶段

1. **寻找**：源力从已有的关系里找出来，来源是顾客、市场、文化、社会四个方向，不凭空创造。
2. **设计**：把源力落到五件事上，依次是锚定“为什么”、明确“是谁、不是谁”、让目标人群看到、落实到产品和服务、持续听反馈。
3. **坚持**：产品和服务不走样；内容持续输出但不编故事；每季度复测一次。

## 6. 判断参照

| 正确的源力 | 错误的源力 |
|---|---|
| 真实性 | 追求快速成功 |
| 持续创新 | 模仿他人 |
| 用户至上 | 忽视用户反馈 |
| 长期视角 | 过度扩张 |
| 内部凝聚力 | 忽略内部管理 |
| 社会责任 | 只注重利润 |
| 开放合作 | 过度依赖外部资源 |
| 持续学习 | 拒绝改变 |
| 应对风险 | 缺乏危机意识 |
| 注重细节 | 过于复杂 |

坚持源力的五条红线：不偏航、不妥协、不浮躁、不复制、不停滞。

## 7. 与定位理论的关系

品牌源力不否定定位。定位回答“在顾客心里占什么位置”，源力回答“凭什么占得住”。先有源力，定位才有依据。
